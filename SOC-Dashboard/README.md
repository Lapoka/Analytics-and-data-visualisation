# Задание № 1 — SOC Dashboard

Интерактивный дашборд для анализа карточек инцидентов информационной безопасности (SOC).

## Используемые технологии

- **Python 3.12** — обработка и анализ данных;
- **Taipy GUI** — интерактивный веб-интерфейс;
- **Plotly** — визуализация данных;
- **Pandas** — работа с таблицами;
- **Parquet** — формат хранения исходного датасета.

## Установка и запуск

### 1. Требования

Необходимы Python 3.12 и менеджер пакетов uv.

### 2. Перейти в каталог проекта

Из корня репозитория:

```bash
cd SOC-Dashboard
```

### 3. Создать виртуальное окружение

```bash
uv venv
```

### 4. Установить зависимости

```bash
uv pip install -r requirements.txt
```

### 5. Добавить исходные данные

Поместите файл `iavd_incidents_raw_target.parquet` в каталог `data/`.

Ожидаемый путь:

```text
SOC-Dashboard/data/iavd_incidents_raw_target.parquet
```

### 6. Запустить приложение

```bash
uv run python app.py
```

После запуска откройте в браузере адрес, который Taipy выведет в терминале (обычно `http://127.0.0.1:5000`).

## Аналитические вопросы

Дашборд помогает ответить на следующие вопросы:

1. Как распределяются карточки SOC по итоговым вердиктам?
2. Как связаны ложноположительные срабатывания и критичность инцидентов?
3. В какие часы суток поступает наибольшее количество карточек?
4. Какие правила обнаружения формируют наибольшую нагрузку?
5. Для каких правил характерна наиболее высокая доля ложноположительных срабатываний?
