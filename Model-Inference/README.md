# Задание № 2 — Model Inference

Интерактивный дашборд для анализа результатов инференса модели машинного обучения, предназначенной для обнаружения инцидентов информационной безопасности (SOC).

## Используемые технологии

- **Python 3.12** — обработка и анализ данных;
- **Taipy GUI** — интерактивный веб-интерфейс;
- **Plotly** — визуализация данных;
- **Pandas** — работа с таблицами;
- **Parquet** — формат хранения исходных данных.


## Установка и запуск

### 1. Требования

Необходимы Python 3.12 и менеджер пакетов uv.

### 2. Перейти в каталог проекта

Из корня репозитория:

```bash
cd Model-Inference
```

### 3. Создать виртуальное окружение

```bash
uv venv
```

### 4. Установить зависимости

```bash
uv pip install -r requirements.txt
```

### 5. Добавить исходные данные

Поместите файл `MODEL_PREDICTIONS_target.parquet` в каталог `data/`.

Ожидаемый путь:

```text
Model-Inference/data/MODEL_PREDICTIONS_target.parquet
```

Если используемая версия приложения также обращается к `iavd_incidents_raw3_target.parquet`, этот файл необходимо поместить в тот же каталог.

### 6. Запустить приложение

```bash
uv run python app.py
```

После запуска откройте в браузере адрес, который Taipy выведет в терминале (обычно `http://127.0.0.1:5000`).

## Аналитические вопросы

Дашборд помогает ответить на следующие вопросы:

1. Как распределяются предсказания модели между классами?
2. Сколько правильных и ошибочных решений принимает модель?
3. Как часто модель пропускает реальные инциденты информационной безопасности?
4. Для каких уровней критичности характерно наибольшее количество ошибок?
5. Как связаны ошибки модели и предсказанная вероятность инцидента?

## Описание модели и данных

Исследуемая модель: **`wlarf-dec-jun-v3`**.

Положительный класс (`y = 1`) соответствует реальному инциденту информационной безопасности.

Исходный набор содержит **19 393 предсказания**, из которых **15 839 имеют валидную разметку**. Метрики качества рассчитываются только по размеченным карточкам.
