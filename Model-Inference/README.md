# Задание № 2 — инференс ML-модели SOC

Taipy-приложение для оценки модели `wlarf-dec-jun-v3`.

## Установка (Arch Linux / fish)

Если среда ещё не создана:
```fish
uv venv --python 3.12
```
Установить зависимости:
```fish
uv pip install --python .venv/bin/python -r requirements.txt
```
Разместить `MODEL_PREDICTIONS_target.parquet` в `data/`.

Запуск (при конфликте настроек часового пояса Linux):
```fish
set -x TZ Europe/Moscow
.venv/bin/python app.py
```
Открыть http://127.0.0.1:5001

Переменная TZ нужна лишь для обхода конфликта конфигурации среды; для реальных временных меток используем UTC. Вместо Europe/Moscow можно задать свой действительный часовой пояс.

## Методика
- Все предсказания учитываются в распределении классов.
- Метрики, FN/FP и матрица ошибок вычисляются только по `Flag_ValidLabel=1`, `y` в `{0,1}`.
- Точное значение рабочих настроек модели из одного датасета не доказано; порог ~0.18 восстановлен по сохранённым `y_pred` и вероятностям.
- Положительный класс — `y=1`, настоящий инцидент.
- Фильтры изменяют анализируемый срез; метрики могут отличаться от значений для полного набора.
